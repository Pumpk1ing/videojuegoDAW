## EL DINERO CRECE DE LOS ÁRBOLES

Intento de juego en terminal que consiste en comprar plantas, llevarlas a tu parcela y sobrevivir la mayor cantidad de turnos posibles.

## Ejecutar

Utiliza en el IDE la opción ejecutar (?) / compila el archivo con javac App.java y ejecuta con java App

## Reglas

Utiliza los números propuestos en la terminal para moverte por los menús e interactuar con el juego (utilizar cualquier otra cosa que no son los números seleccionados puede dar lugar a errores y que se cuelgue el juego)
